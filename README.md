# 🤖 Intelligent Email Triage System

## Overview

Intelligent Email Triage System is an AI-powered workflow automation platform that classifies, prioritizes, routes, and responds to incoming emails using NLP techniques.

The system combines:
- Intent classification
- Sentiment analysis
- Urgency detection
- Task extraction
- Automated routing
- AI-generated reply suggestions

This project demonstrates how AI and RPA can automate enterprise communication workflows.

---

## Features

- Email categorization
- Urgency scoring
- Sentiment detection
- Department routing
- Suggested replies
- Task extraction

---

## Architecture

Email → NLP Processing → Classification → Routing → Suggested Action
